# Third-party notices

Goku is a derivative font and includes outlines from the following projects.

## GohuFont

The text design is derived from GohuFont uni14 by Hugo Chargois, pinned as the
`vendor/gohufont` submodule at commit
`cc36b8c9fed7141763e55dcee0a97abffcf08224`.

GohuFont is distributed under the WTFPL version 2. The complete upstream text
is included with release assets as `GohuFont-WTFPL.txt` and in the source tree
at `vendor/gohufont/COPYING-LICENSE`.

Upstream: <https://github.com/hchargois/gohufont>

## Nerd Fonts glyphs

Goku is patched with Nerd Fonts Patcher 3.4.0. Nerd Fonts aggregates icon sets
whose copyrights and licenses remain with their respective upstream projects.
The authoritative source list for the pinned patcher release is:

<https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/src/glyphs>

Nerd Fonts' license audit is available at:

<https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/license-audit.md>

Nerd Fonts project: <https://github.com/ryanoasis/nerd-fonts>
