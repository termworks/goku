# Goku 1.200

Goku 1.200 is the first numeric-weight release. One `Goku.ttc` contains nine
upright weights (`Goku-100` through `Goku-900`) and nine matching italics.

Highlights:

- exact Gohu-derived Regular and real Bold anchors at weights 400 and 700;
- smooth, distinct terminal-size rendering at every 100-unit step;
- complete Nerd Font and terminal-symbol coverage in every face;
- unchanged icon geometry and monospaced advances across all weights;
- bounded small-size hinting for crisp text;
- reproducible one-file release with SHA-256 and validation manifest.

This release removes the temporary named-weight family. Select exact faces by
PostScript name, for example `Goku-200`, `Goku-700`, `Goku-200Italic`, and
`Goku-700Italic`.
